# FinScope · 全球财报数据采集台

把原来那几个一次性的 Python 抓取脚本（`world_stocks_financial.py`、`consolidate_stock_codes.py`、
`main_hybrid.py` …）变成了一个带界面的应用：左边挑范围，右边看结果，跑完直接导出。

- **前端**：Vite + React + TypeScript（无 UI 框架，纯 CSS 设计系统）
- **后端**：FastAPI + yfinance，负责股票池检索、财报抓取、任务进度推送和导出

---

## 快速开始

两个进程，各开一个终端。

```bash
.venv/Scripts/python.exe -m uvicorn backend.app.main:app --port 8787 --reload
```

```bash
cd frontend && npm install && npm run dev
```

然后打开 http://localhost:5173 。

首次使用需要安装后端依赖：

```bash
.venv/Scripts/pip.exe install -r backend/requirements.txt
```

想只跑一个进程，就先 `cd frontend && npm run build`，之后 uvicorn 会自动把
`frontend/dist` 挂到 `/`，直接访问 http://127.0.0.1:8787 即可。

## 相比原脚本改了什么

### 1. 非美股终于能抓到了

原来的 `world_stocks_financial.py` 在美股以外几乎全军覆没，根因有三个，现在都修了：

| 原问题 | 现在 |
| --- | --- |
| 季报为空就直接返回空 DataFrame，只在**抛异常**时才回退年报。欧洲、澳洲多数公司按半年报披露，季报表恒为空。 | 以利润表为基准判断口径，季报为空自动回退年报（`fetcher.py`）。雀巢、LVMH、必和必拓都能正常取到。 |
| 交易所后缀靠子串匹配：`'de' in exchange` 会命中 Sweden、Denmark；货币判断 `'L' in code` 会把 AAPL 标成 GBP。 | 后缀与市场在 `markets.py` 里显式登记；报表货币直接读 Yahoo 的 `financialCurrency`（汇丰因此正确标记为 USD 而非 GBP）。 |
| 股票池来自本地 `dax.csv` / `FTSE.csv`，只有几十个代码，且 A 股、港股依赖 akshare 且经常连不上。 | 改用 Yahoo 股票筛选器实时枚举，覆盖 **48 个可用市场**，从上交所到布达佩斯、沙特、圣保罗。 |

### 2. 跨境挂牌过滤

直接按市值枚举非美市场，前几十名全是苹果、英伟达在当地交易所的挂牌线。Yahoo 没有给公司注册地
字段（它的 `region` 是**调用方**的地区，不是公司的），所以用了两个可观测信号：

- 存托凭证板块（`dr_market`）直接排除；
- 日成交额 / 市值低于 1e-5 的挂牌线视为休眠的跨境线（NVDA.SW 约 0.0005%，NESN.SW 约 0.13%）。

再加上按「名称前缀 + 市值相差 3% 以内」合并同一公司的多条挂牌线（HSBA.L / HSBAL.XC）。

德国、意大利、巴西还需要额外开启「只保留以本地货币记账的公司」才能滤净——这一项默认关闭，
因为英国的汇丰、壳牌用美元编报，开了会被误伤。界面上两个开关是分开的，取舍交给你。

### 3. 界面上全部可调的范围

- **市场**：48 个市场，按大洲分组，带预设（仅美股 / 全球七大 / 发达市场 / 亚太 / 欧洲 / 新兴市场）
- **数量**：每个市场 5–500 只，外加「跳过前 N 名」用于分批抓取
- **市值区间**：上下限各一个对数刻度滑块
- **行业板块**：11 个 GICS 板块多选
- **排序**：市值 / 成交量 / 股价 / 市盈率，升降序可切
- **报告期**：季报 / 年报 / 自动，最近 1–20 期，另可指定起止日期
- **字段**：81 个字段分 6 组自由勾选，带 5 个预设（核心 / 全部 / 仅估值 / 三大报表 / 比率分析）
- **抓取参数**：并发 1–16、请求间隔 0–2 秒

### 4. 字段从 30 个扩到 81 个

三大报表明细更全（商誉、无形资产、有息负债、留存收益、股权激励、回购、EBITDA…），
新增估值快照（市值、PE、PB、PS、EV/EBITDA、股息率、Beta…）和 12 个衍生指标
（毛利率、营业利润率、净利率、研发费用率、ROA、ROE、流动比率、速动比率、实际税率…）。

衍生指标所依赖的原始字段会自动补齐——勾了 ROE 但没勾净利润，后端会自己把它加进抓取清单。

### 5. 任务化运行

抓取在后台线程池里跑，进度通过 SSE 实时推到界面：逐只股票的成功/失败日志、计数器、可中途停止。
结果支持排序、搜索、分页，导出 CSV（中文表头，UTF-8 BOM，Excel 直接打开不乱码）、Excel、JSON。

## 代码结构

```
backend/app/
  markets.py    60 个市场的登记表：Yahoo 地区码、后缀、货币、分组
  universe.py   股票池检索：筛选器分页、跨境挂牌过滤、代码搜索
  fields.py     81 个字段的定义、yfinance 行名别名、衍生指标公式
  fetcher.py    单只股票的抓取：季报/年报回退、货币归一、比率计算
  jobs.py       任务管理：线程池、进度事件、取消
  export.py     CSV / Excel / JSON 导出
  main.py       FastAPI 路由

frontend/src/
  App.tsx              布局与配置状态
  components/          市场选择、字段选择、代码搜索、数据表格、UI 原语
  lib/                 API 客户端、类型、格式化、任务 SSE hook
  styles/              设计令牌、基础样式、组件样式
```

原有的 Python 脚本保持原样，没有删改。

## 已知边界

- 数据源是 Yahoo Finance，非官方接口，偶尔会限流或某只股票缺数据；并发调高时把请求间隔一起调高。
- 有 9 个市场（越南、菲律宾、埃及、俄罗斯等）Yahoo 筛选器返回空，界面里默认隐藏，可手动展开。
- A 股的 `.info` 常缺市值，界面会回退用筛选器返回的市值填补。
- 任务结果只存在内存里，重启后端会丢失；需要留存请先导出。

数据仅供研究使用，不构成投资建议。
